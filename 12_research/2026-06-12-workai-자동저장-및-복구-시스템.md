# WorkAI 자동저장 및 복구 시스템 리서치

## 1. 현재 상태 분석

### 문제점
- 수동 저장만 지원 (Ctrl+S 또는 저장 버튼)
- 자동저장 미구현
- 브라우저 종료 시 작업 데이터 손실 위험
- 세션 복구 기능 부재

## 2. 개선 방안

### 2.1 자동저장 시스템

#### 자동저장 전략
- **딜레이 기반 자동저장**: 변경 후 30초 뒤 자동저장
- **이벤트 기반 자동저장**: 주요 액션 후 즉시 저장
- **포커스 이탈 자동저장**: 탭/윈도우 이탈 시 저장
- **최소 변경 임계값**: 최소 10자 이상 변경 시에만 저장

#### 자동저장 구현
```typescript
// src/hooks/useAutoSave.ts
import { useEffect, useRef, useCallback } from 'react';

interface AutoSaveOptions {
  delay?: number;
  minChanges?: number;
  onSave: () => Promise<void>;
}

export function useAutoSave(
  data: any,
  options: AutoSaveOptions
) {
  const { delay = 30000, minChanges = 10, onSave } = options;
  const lastSavedRef = useRef<string>('');
  const changeCountRef = useRef(0);
  const timeoutRef = useRef<NodeJS.Timeout>();

  const checkAndSave = useCallback(async () => {
    const currentData = JSON.stringify(data);
    if (currentData !== lastSavedRef.current && 
        changeCountRef.current >= minChanges) {
      await onSave();
      lastSavedRef.current = currentData;
      changeCountRef.current = 0;
    }
  }, [data, onSave, minChanges]);

  useEffect(() => {
    changeCountRef.current++;
    
    if (timeoutRef.current) clearTimeout(timeoutRef.current);
    timeoutRef.current = setTimeout(checkAndSave, delay);

    return () => {
      if (timeoutRef.current) clearTimeout(timeoutRef.current);
    };
  }, [data, delay, checkAndSave]);

  // 브라우저 이탈 시 저장
  useEffect(() => {
    const handleBeforeUnload = () => {
      if (changeCountRef.current > 0) {
        checkAndSave();
      }
    };
    window.addEventListener('beforeunload', handleBeforeUnload);
    return () => window.removeEventListener('beforeunload', handleBeforeUnload);
  }, [checkAndSave]);
}
```

#### 자동저장 상태 표시 UI
- 헤더에 자동저장 상태 표시 (아이콘 + 텍스트)
- 저장 중 표시: 스피너 아이콘 + "저장 중..."
- 저장 완료 표시: 체크 아이콘 + "저장됨"
- 저장 실패 표시: 경고 아이콘 + "저장 실패"

### 2.2 로컬 스토리지 복구 시스템

#### 복구 데이터 구조
```typescript
interface RecoveryData {
  id: string;
  timestamp: number;
  data: Presentation;
  metadata: {
    title: string;
    slideCount: number;
    lastModified: Date;
  };
}
```

#### 복구 시나리오
1. **브라우저 재시작**: 마지막 자동저장 데이터 복구
2. **탭 닫기 후 재개**: 자동저장 데이터 복원
3. **오류 복구**: 충돌 전 자동저장 데이터 복원
4. **수동 복구**: 저장 목록에서 선택적 복원

### 2.3 클라우드 동기화

- 충돌 해결: 최신 변경사항 우선

## 3. 복구 시스템 구현

### 3.1 자동 복구 다이얼로그
```typescript
// src/components/RecoveryDialog.tsx
interface RecoveryDialogProps {
  isOpen: boolean;
  onRecover: (data: RecoveryData) => void;
  onDismiss: () => void;
  recoveryData: RecoveryData[];
}

export function RecoveryDialog({ 
  isOpen, onRecover, onDismiss, recoveryData 
}: RecoveryDialogProps) {
  if (!isOpen || recoveryData.length === 0) return null;
  
  return (
    <Dialog open={isOpen} onOpenChange={onDismiss}>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>작업 복구</DialogTitle>
          <DialogDescription>
            이전에 편집 중이던 작업이 있습니다.
          </DialogDescription>
        </DialogHeader>
        
        <div className="space-y-3">
          {recoveryData.map((item) => (
            <RecoveryItem 
              key={item.id}
              data={item}
              onRecover={() => onRecover(item)}
            />
          ))}
        </div>
        
        <DialogFooter>
          <Button variant="outline" onClick={onDismiss}>
            새 작업 시작
          </Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
}
```
