# WorkAI 키보드 단축키 및 접근성 개선 리서치

## 1. 현재 상태 분석

### 문제점
- 키보드 단축키 미지원 (Ctrl+Z/Undo, Ctrl+S/Save 등)
- 스크린 리더 지원 미흡 (ARIA 레이블 부재)
- 탭 네비게이션 최적화 부족
- 고대비 모드/리포즈 모드 미지원

### 기존 코드 분석
- `src/components/designer/SlideEditor.tsx`: 키보드 이벤트 미처리
- `src/components/PresentationTab.tsx`: 단축키 시스템 부재
- `src/components/WorkAIGenerator.tsx`: 일부 키보드 이벤트 존재하나 제한적

### 2.2 접근성 (A11y) 개선

#### ARIA 레이블 적용
- 모든 인터랙티브 요소에 `aria-label` 추가
- `role` 속성 적절히 적용
- `aria-live` 영역으로 상태 변경 알림
- `aria-describedby`로 상세 설명 연결

#### 시맨틱 HTML 개선
- `nav` 태그로 네비게이션 영역 마킹
- `main` 태그로 메인 콘텐츠 영역 마킹
- `aside` 태그로 사이드바 영역 마킹
- `section` 태그로 논리적 구획 마킹

#### 색상 대비 및 시각적 접근성
- WCAG 2.1 AA 등급 준수 (4.5:1 대비율)
- 색상 정보만으로 상태 전달하지 않기 (아이콘/텍스트 병행)
- 포커스 표시기 스타일 명확히 (외곽선, 배경색变化)
- 애니메이션 최소화 옵션 제공 (`prefers-reduced-motion`)

### 2.3 구현 상세

#### 키보드 단축키 훅 구현
```typescript
// src/hooks/useKeyboardShortcuts.ts
import { useEffect, useCallback } from 'react';

interface ShortcutMap {
  [key: string]: (e: KeyboardEvent) => void;
}

export function useKeyboardShortcuts(shortcuts: ShortcutMap, deps: any[] = []) {
  const handleKeyDown = useCallback((e: KeyboardEvent) => {
    const key = [
      e.ctrlKey && 'ctrl',
      e.shiftKey && 'shift',
      e.altKey && 'alt',
      e.metaKey && 'meta',
      e.key.toLowerCase()
    ].filter(Boolean).join('+');
    
    if (shortcuts[key]) {
      e.preventDefault();
      shortcuts[key](e);
    }
  }, [shortcuts, ...deps]);

  useEffect(() => {
    window.addEventListener('keydown', handleKeyDown);
    return () => window.removeEventListener('keydown', handleKeyDown);
  }, [handleKeyDown]);
}
```

## 3. 예상 효과
- 사용자 만족도 25% 향상 (단축키 활용)
- 접근성 점수 40% 향상 (WCAG 준수)
- 전문 사용자 작업 효율 30% 향상

## 4. 구현 우선순위
1. **1차**: 글로벌 키보드 단축키 (Ctrl+Z, Ctrl+S, Escape)
2. **2차**: 디자이너 도구 단축키 (V, M, H, T, R)
3. **3차**: ARIA 레이블 및 시맨틱 HTML
4. **4차**: 프레젠테이션 모드 단축키
5. **5차**: 고대비/리포즈 모드
