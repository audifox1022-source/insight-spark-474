### 2.1 배치 슬라이드 재생성

#### 배치 재생성 전략
- **범위 선택**: 개별/전체/범위 지정 재생성
- **병렬 처리**: 여러 슬라이드 동시 재생성
- **진행률 표시**: 실시간 진행 상태 표시
- **중간 저장**: 완료된 슬라이드 즉시 반영

#### 배치 재생성 구현
```typescript
// src/lib/batch-regeneration.ts
interface BatchRegenOptions {
  slideIndices: number[];
  instruction: string;
  parallel?: boolean;
  maxConcurrent?: number;
}

interface BatchRegenProgress {
  total: number;
  completed: number;
  failed: number;
  current: number;
  status: 'running' | 'completed' | 'failed';
}

export async function batchRegenerateSlides(
  presentation: Presentation,
  options: BatchRegenOptions,
  onProgress: (progress: BatchRegenProgress) => void
): Promise<Presentation> {
  const { slideIndices, instruction, parallel = true, maxConcurrent = 3 } = options;
  const progress: BatchRegenProgress = {
    total: slideIndices.length,
    completed: 0,
    failed: 0,
    current: 0,
    status: 'running'
  };

  const processSlide = async (index: number) => {
    progress.current = index;
    onProgress(progress);
    
    try {
      const result = await aiService.regenerateSlide({
        slideIndex: index,
        currentSlide: presentation.slides[index],
        userInstruction: instruction
      });
      
      if (result?.slide) {
        presentation.slides[index] = result.slide;
        progress.completed++;
      } else {
        progress.failed++;
      }
    } catch (error) {
      progress.failed++;
      console.error(`Slide ${index} regeneration failed:`, error);
    }
    
    onProgress(progress);
  };

  if (parallel) {
    // 병렬 처리 (최대 동시 실행 수 제한)
    const chunks = chunkArray(slideIndices, maxConcurrent);
    for (const chunk of chunks) {
      await Promise.all(chunk.map(processSlide));
    }
  } else {
    // 순차 처리
    for (const index of slideIndices) {
      await processSlide(index);
    }
  }

  progress.status = progress.failed > 0 ? 'failed' : 'completed';
  onProgress(progress);
  
  return presentation;
}

function chunkArray<T>(array: T[], size: number): T[][] {
  const chunks: T[][] = [];
  for (let i = 0; i < array.length; i += size) {
    chunks.push(array.slice(i, i + size));
  }
  return chunks;
}
```

### 2.2 버전 관리 시스템

#### 버전 데이터 구조
```typescript
interface PresentationVersion {
  id: string;
  timestamp: number;
  data: Presentation;
  metadata: {
    author: string;
    changeDescription: string;
    slideCount: number;
    autoGenerated: boolean;
  };
  diff?: VersionDiff;
}

interface VersionDiff {
  added: number[];
  removed: number[];
  modified: number[];
  unchanged: number[];
}
```

#### 버전 관리 기능
1. **자동 버전 생성**: 주요 변경 시 자동 버전 생성
2. **수동 버전 생성**: 사용자가 특정 시점 저장
3. **버전 비교**: 두 버전 간 차이점 시각화
4. **버전 복원**: 특정 버전으로 되돌리기
5. **버전 히스토리**: 시간순 버전 목록 표시

#### 버전 비교 알고리즘
```typescript
// src/lib/version-diff.ts
export function compareVersions(
  oldVersion: Presentation,
  newVersion: Presentation
): VersionDiff {
  const oldSlides = new Map(oldVersion.slides.map((s, i) => [s.id || i, s]));
  const newSlides = new Map(newVersion.slides.map((s, i) => [s.id || i, s]));
  
  const added: number[] = [];
  const removed: number[] = [];
  const modified: number[] = [];
  const unchanged: number[] = [];
  
  // 새 버전에만 있는 슬라이드 (추가됨)
  newVersion.slides.forEach((slide, index) => {
    const key = slide.id || index;
    if (!oldSlides.has(key)) {
      added.push(index);
    }
  });
  
  // 이전 버전에만 있는 슬라이드 (삭제됨)
  oldVersion.slides.forEach((slide, index) => {
    const key = slide.id || index;
    if (!newSlides.has(key)) {
      removed.push(index);
    }
  });
  
  // 양쪽에 있는 슬라이드 비교
  newVersion.slides.forEach((slide, index) => {
    const key = slide.id || index;
    if (oldSlides.has(key)) {
      const oldSlide = oldSlides.get(key)!;
      if (JSON.stringify(oldSlide) !== JSON.stringify(slide)) {
        modified.push(index);
      } else {
        unchanged.push(index);
      }
    }
  });
  
  return { added, removed, modified, unchanged };
}
```
