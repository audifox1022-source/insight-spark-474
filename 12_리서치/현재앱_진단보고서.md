| 항목 | 내용 |
|------|------|

## 2. 프로젝트 구조 분석

### 2.1 디렉토리 구조
```
src/
├── components/          # UI 컴포넌트 (42개)
│   ├── ai/             # WorkAIGenerator (BANANA NL 엔진)
│   ├── audio/          # Audio Lab (오디오 분석)
│   ├── designer/       # 슬라이드 에디터 (15개 파일)
│   ├── pdf/            # PDF 편집기
│   └── ui/             # 공통 UI 컴포넌트
├── hooks/              # 커스텀 훅 (6개)
├── lib/                # 유틸리티 라이브러리 (40+개)
├── pages/              # 페이지 (Auth, Index, NotFound)
├── services/ai/        # AI 서비스 (Gemini 연동)
├── store/              # Zustand 스토어 (6개)
├── types/              # 타입 정의 (4개)
└── utils/              # 유틸리티 (5개)
```

### 2.2 라우팅 구조
| 경로 | 컴포넌트 | 인증 |
|------|----------|------|
| `/auth` | Auth | 공개 |
| `/` | Index (메인 플랫폼) | 필요 |
| `/generator` | WorkAIGenerator | 필요 |
| `*` | NotFound | 공개 |

### 2.3 핵심 기능 모듈
1. **발표자료 생성** (Index.tsx + usePresentation.ts) - Gemini AI 기반
2. **슬라이드 에디터** (SlideEditor.tsx) - 실시간 편집
3. **AI 번역** (TranslatorWorkspace.tsx) - 다국어 번역
4. **오디오 분석** (AudioLabWorkspace.tsx) - 음성/음악 분석
5. **PDF 편집** (PDFEditorWorkspace.tsx) - 오브젝트 기반 편집

## 3. 기술 스택 상세

### 3.1 프론트엔드
- **React 18**: Suspense, lazy, memo 활용
- **TypeScript**: strict 모드
- **Vite 8**: 빌드 도구
- **Tailwind CSS 3**: 다크모드 지원
- **Zustand 5**: 상태 관리 (6개 스토어)
- **React Router 6**: 라우팅
- **Framer Motion**: 애니메이션
- **React Query**: 서버 상태 관리

### 3.2 백엔드
- **Express.js**: API 서버 (server.js)
- **Supabase**: 인증 + 데이터베이스
- **Gemini API**: AI 엔진 (프록시 패턴)
- **Vercel Blob**: 파일 업로드

### 3.3 데이터 저장
- **Supabase Auth**: 사용자 인증
- **IndexedDB (Zustand persist)**: 발표자료 로컬 저장
- **localStorage**: 테마, 즐겨찾기 설정
- **Supabase Storage**: 파일 저장 (오디오)

## 4. 발견된 문제점

### 4.1 치명적 문제
| 문제 | 위치 | 영향 |
|------|------|------|
| Supabase project ref 불일치 시 전체 앱 차단 | App.tsx:222 | 환경변수 오류 시 앱 사용 불가 |
| WorkAIGenerator 모의 응답 사용 | WorkAIGenerator.tsx:152 | 실제 AI 기능 미작동 |
| NotFound 페이지 영어 사용 | NotFound.tsx | 한국어 사용자 불편 |

### 4.2 안정성 문제
| 문제 | 위치 | 영향 |
|------|------|------|
| 에러 바운더리 미적용 (Audio, PDF) | 전체 | 컴포넌트 크래시 시 전체 중단 |
| API 타임아웃 5초로 짧음 | client.ts:7 | 네트워크 불안정 시 데이터 손실 |
| 세션 만료 시 명확한 피드백 부재 | ProtectedRoute | 사용자 혼란 유발 |

### 4.3 사용성 문제
| 문제 | 위치 | 영향 |
|------|------|------|
| 모바일 네비게이션 미지원 | Index.tsx | 모바일 사용 불가 |
| 빈 화면 처리 부족 | 슬라이드 에디터 | 데이터 없을 때 UX 저하 |
| 로딩 상태 불일치 | 여러 컴포넌트 | 사용자 불안감 유발 |

### 4.4 코드 품질
| 문제 | 위치 | 영향 |
|------|------|------|
| 하드코딩된 문자열 다수 | 여러 파일 | 다국어 지원 불가 |
| 중복 컴포넌트 패턴 | designer/ | 유지보수 어려움 |
| `any` 타입 사용 | Slide 타입:41 | 타입 안정성 저하 |
