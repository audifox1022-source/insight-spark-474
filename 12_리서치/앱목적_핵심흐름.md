# 앱 목적 및 핵심 흐름 분석

## 1. 앱의 핵심 목적

**WorkAI**는 AI 기반 업무 자동화 플랫폼으로, 다음 4가지 핵심 기능을 제공합니다:

1. **AI 발표자료 생성**: 문서/텍스트를 입력하면 AI가 전문적인 발표 슬라이드를 자동 생성
2. **AI 번역**: 다국어 문서 번역 및 분석
3. **오디오 분석**: 음성/음악 파일의 심층 분석
4. **PDF 편집**: 오브젝트 기반 PDF 편집 및 내보내기

## 2. 주요 사용자

| 사용자 유형 | 사용 목적 | 빈도 |
|-------------|-----------|------|
| 기획자/매니저 | 발표자료 빠르게 생성 | 높음 |
| 비즈니스 전문가 | 보고서/제안서 작성 | 높음 |
| 마케터 | 프레젠테이션 제작 | 중간 |
| 번역가/통역사 | 문서 번역 | 중간 |
| 리서처 | 데이터 분석 리포트 | 낮음 |

## 3. 핵심 사용자 흐름

### 3.1 발표자료 생성 흐름 (가장 중요)
```
1. 파일 업로드 또는 주제 입력
   ↓
2. 발표 브리프 작성 (제목, 목표, 청중, 어조)
   ↓
3. 생성 설정 (스타일, 분량, 톤앤매너)
   ↓
4. AI 실행 계획 생성 및 승인
   ↓
5. 슬라이드 자동 생성
   ↓
6. 슬라이드 에디터에서 편집
   ↓
7. 내보내기 (PDF/PPTX)
```

### 3.2 AI 번역 흐름
```
1. 텍스트 입력 또는 파일 업로드
   ↓
2. 대상 언어 선택
   ↓
3. AI 분석 및 번역
   ↓
4. 결과 확인 및 수정
   ↓
5. 내보내기 (DOCX/TXT)
```

### 3.3 오디오 분석 흐름
```
1. 오디오 파일 업로드 (최대 500MB)
   ↓
2. Vercel Blob 업로드
   ↓
3. AI 음성/음악 식별
   ↓
4. 심층 분석 (전사, 감정, 구조 등)
   ↓
5. 리포트 확인 및 다운로드
```

### 3.4 PDF 편집 흐름
```
1. PDF 파일 업로드
   ↓
2. 페이지 선택 및 미리보기
   ↓
3. 텍스트/도형/이미지 편집
   ↓
4. 저장 및 내보내기
```

## 4. 가장 중요한 기능

**1순위: 발표자료 생성**
- 사용자가 가장 많이 사용하는 기능
- 앱의 핵심 가치 제안
- 수익 모델과 직결

**2순위: 슬라이드 에디터**
- 생성된 발표자료의 품질 결정
- 사용자 만족도에 직접 영향

**3순위: 내보내기 (PDF/PPTX)**
- 최종 산출물
- 사용자가 실제로 사용하는 결과물

## 5. 사용자가 얻어야 하는 최종 결과

| 기능 | 기대 결과 |
|------|-----------|
| 발표자료 | 전문적인 수준의 프레젠테이션 슬라이드 |
| 번역 | 정확하고 자연스러운 다국어 번역 |
| 오디오 분석 | 상세한 음성/음악 분석 리포트 |
| PDF 편집 | 편집된 고품질 PDF 문서 |

## 6. 목적 달성을 방해하는 부족한 부분

### 6.1 발표자료 생성
| 부족한 부분 | 심각도 | 영향 |
|-------------|--------|------|
| 초기 로딩 시간 김 | 높음 | 사용자 이탈 |
| 생성 실패 시 복구 어려움 | 높음 | 데이터 손실 |
| 템플릿 선택 기능 부족 | 중간 | 사용자 선택 폭 제한 |
| 미리보기 품질 저하 | 중간 | 품질 확인 어려움 |

### 6.2 슬라이드 에디터
| 부족한 부분 | 심각도 | 영향 |
|-------------|--------|------|
| 모바일 편집 불가 | 높음 | 모바일 사용자 차단 |
| 실행 취소/다시 실행 불안정 | 중간 | 편집 안정성 저하 |
| 드래그앤드롭 미지원 | 중간 | 편집 효율 저하 |

### 6.3 내보내기
| 부족한 부분 | 심각도 | 영향 |
|-------------|--------|------|
| PPTX 서식 손실 | 높음 | 사용자 불만 |
| PDF 해상도 저하 | 중간 | 품질 저하 |
| 대용량 내보내기 실패 | 중간 | 사용자 불편 |

## 7. 개선 우선순위

### 즉시 개선 (P0)
1. **에러 복구 메커니즘** - 생성 중단 시 이전 상태 복원
2. **빈 화면 처리** - 데이터 없을 때 안내 메시지
3. **로딩 상태 일관성** - 모든 화면에서 일관된 로딩 UI

### 단기 개선 (P1)
1. **모바일 네비게이션** - 모바일 메뉴 추가
2. **입력 검증 강화** - 잘못된 입력에 대한 안내
3. **세션 만료 처리** - 명확한 재로그인 안내

### 중기 개선 (P2)
1. **성능 최적화** - 초기 로딩 시간 단축
2. **테스트 커버리지 확대** - 핵심 기능 테스트 추가
3. **코드 품질 개선** - any 타입 제거, 중복 코드 정리
