# Antigravity Developer Guide (Work AI)

## Development Workflow
- **Wiki First**: Always check `wiki/hot.md` to see where we left off.
- **Continuous Documentation**: Update `wiki/log.md` after every major feature completion.
- **Theme Awareness**: Use Tailwind classes that support dark mode (`dark:...`).
- **Data Safety**: Never modify `.env` or delete API keys.

## Commands & Skills
- **Build**: `npm run build`
- **Verification**: Use the browser subagent to test UI changes.
- **Knowledge Management**: Use the `wiki/` directory to store detailed domain knowledge (e.g., Gemini Audio API quirks).

## LLM Wiki Pattern
1. Read `wiki/hot.md` for recent context.
2. Read `wiki/index.md` for project structure.
3. Update `wiki/hot.md` at the end of a session to help the next version of yourself.
